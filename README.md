#  Stock Portal — 국내주식 & 해외주식 통합 대시보드

초보자도 한눈에 이해할 수 있는 주식 분석 대시보드 포털입니다.  
애플(Apple) 스타일의 인터랙티브 UI와 4단계 스토리라인 차트 주석을 제공합니다.

---

## 🌟 주요 특징

1. **국내주식 / 해외주식 듀얼 탭 지원**:
   - **해외주식**: 조비 에비에이션(JOBY), 허사이 그룹(HSAI), 애플(AAPL)
   - **국내주식**: 삼성전자(005930.KS), 조비(001550.KS)
2. **초보자 맞춤형 차트 주석 (In-Canvas Annotations)**:
   - 1달 최고가(★), 최저가(▼), 최근 마감가(●), 시작일 기준선(주황 점선) 자동 표시
   - 4구간(바닥 다지기 → 거래량 폭발 → 전고점 터치 → 숨고르기) 스토리라인 카드
3. **새 회사 추가 기능**:
   - 대시보드 내 모달창을 통해 원하는 종목을 실시간으로 추가 모니터링 가능
4. **인쇄 및 PDF 저장 지원**:
   - 상단 `🖨️ 인쇄 / PDF 저장` 버튼 클릭 시 A4 규격에 맞춘 클린 리포트 출력 지원
5. **독립 실행형 리포트(`stock-report.html`)**:
   - 외부 라이브러리 CDN 의존성 없이 단독으로 완전 구동

---

## 📁 파일 구성

* `index.html`: GitHub Pages의 메인 웹 페이지로 배포되는 포털 대시보드
* `stock-report.html`: Chart.js 엔진이 직접 내장되어 오프라인에서도 작동하는 단독 리포트
* `hsai_index.html`: 허사이그룹(HSAI) 전용 초기 대시보드 (보존용)
* `*.json`: 최근 1개월간 수집된 검증된 주가 데이터 (조비, 허사이, 애플, 삼성전자, 국내 조비)
